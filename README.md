# DeskHide

**Спрятать / показать иконки рабочего стола** одной кнопкой или хоткеем.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 3 — «Окна и рабочий стол»** · день 15.

---

## Возможности

- Спрятать или показать иконки на рабочем столе
- **Ctrl+Alt+D** — переключить
- Работа в **трее**, автозапуск с Windows
- Уведомление только при старте с ПК (не при каждом клике)

## Установка

```powershell
git clone https://github.com/vlx0/DeskHide.git
cd DeskHide
python -m pip install -r requirements.txt
pythonw run_deskhide.pyw
```

Или `setup.bat` / `start.bat`.

Нужен **Python 3.10+** с tkinter · Windows.
